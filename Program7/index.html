P7: Design Tokens & Typography System

About Design Tokens

Design tokens are variables used to store design choices like colors, font sizes, and spacing. By changing them in the :root section, the whole page style updates automatically.

Color Tokens

Primary Color: Used for headings and primary accents (#2563eb)

Secondary Color: Used for main titles and dark text (#1e293b)

Typography Scale

Heading XXL (36px)

Heading XL (28px)

Heading LG (20px)

Base text size (16px) - regular paragraph style for reading comfortably.

Extra small text size (14px) - used for captions and footers.
