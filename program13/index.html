Lab P13: Choosing Between Flexbox and Grid for a Shared Layout

When to use Flexbox vs CSS Grid?

As a first-year web development student, understanding when to use Flexbox and when to use Grid is super important. In this lab, we look at how both layout systems work together to share a common page layout.

Flexbox (One-Dimensional)

Best used when arranging items in a single row or a single column.

  • Great for navigation bars.
  • Aligning items inside a header or footer.
  • Simple card lists that wrap around.

CSS Grid (Two-Dimensional)

Best used when managing both rows and columns at the same time.

  • Great for overall page layouts (like newspapers).
  • Complex dashboards and photo galleries.
  • Precise item placement in rows and columns.
